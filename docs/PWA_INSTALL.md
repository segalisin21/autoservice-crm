# Установка CRM на телефон (PWA)

Приложение можно добавить на главный экран и открывать как отдельное приложение. Нужен **HTTPS** (на Railway он есть по умолчанию).

## Android (Chrome)

1. Откройте адрес вашего деплоя (например `https://ваш-проект.up.railway.app`).
2. Войдите в CRM под своим логином.
3. Меню браузера (⋮) → **Установить приложение** или **Добавить на главный экран**.
4. Подтвердите установку. Иконка появится на рабочем столе.

Если пункта нет: убедитесь, что сайт открыт в Chrome, а не во встроенном браузере мессенджера.

## iPhone / iPad (Safari)

1. Откройте URL **только в Safari** (не Chrome/Firefox на iOS).
2. Войдите в CRM.
3. Кнопка **Поделиться** (квадрат со стрелкой).
4. **На экран «Домой»** → **Добавить**.

На iOS установка через Safari обязательна — другие браузеры не добавляют PWA на главный экран.

## После обновления на сервере

Статика кэшируется service worker (`autoservice-v2`). Если интерфейс «застрял» на старой версии:

- закройте вкладку PWA полностью и откройте снова;
- или в настройках сайта в браузере очистите данные для домена.

## Иконки в репозитории

PNG 192×192 и 512×512 генерируются командой:

```bash
node scripts/generate-pwa-icons.js
```

Закоммитьте `public/icons/icon-192.png` и `icon-512.png` после генерации.
