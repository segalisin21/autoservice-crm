# BUG-005 — Пересекающиеся карточки в одном часовом слоте

**Статус:** fixed (2026-06-18)

## Описание
Два заказа у одного мастера в одно время (например 10:00) отображались в одной ячейке без `rowspan` для длинного интервала (10:00–13:00).

## Причина
`rowspan` применялся только если в слоте ровно один заказ (`slotOrders.length === 1`). При пересечении обе карточки складывались в одну ячейку.

## Исправление
- `lib/calendarData.js`: greedy `assignLanes` — каждый заказ в первую полосу без временного пересечения; `lanes[]` с отдельными `byHour` / `coveredBySpan` на полосу.
- `views/partials/schedule-time-grid.ejs`: вложенный цикл по полосам, `colspan` заголовка мастера, `data-lane`.
- `public/css/autoservice.css`: узкие полосы при `maxLanes > 1`, компактные карточки.
