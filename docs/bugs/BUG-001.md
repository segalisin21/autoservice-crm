# BUG-001 — Два мастера создавали две строки работ

**Статус:** fixed (2026-06-18)

## Описание
При выборе двух мастеров на одну работу система делила сумму и создавала две строки в таблице работ и в заказ-наряде (итого удваивалось в UI).

## Ожидаемое поведение
- Одна строка работы с полной суммой для клиента.
- Несколько мастеров через `order_line_payroll` с равными долями.
- ЗП каждого мастера = earned × share_percent.

## Исправление
- `controllers/orderController.js`: `addLine` → одна `order_line` + `syncLinePayrollShares`.
- `views/orders/show.ejs`: чекбоксы мастеров при редактировании; отображение списка имён.
