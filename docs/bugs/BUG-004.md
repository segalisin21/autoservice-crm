# BUG-004 — Нет даты окончания для многодневного заезда

**Статус:** fixed (2026-06-18)

## Описание
Машина на несколько дней не могла быть отражена в системе — только одна дата записи.

## Ожидаемое поведение
- Поле «Дата окончания» на форме заказа.
- В расписании: карточка в день начала с badge «до ДД.ММ»; промежуточные дни без дубля карточки.
- Печать: обе даты.

## Исправление
- Миграция `025_scheduled_end_date.sql` → `orders.scheduled_end_date`.
- Формы, контроллер, `lib/calendarData.js`, `order-card.ejs`, `print.ejs`.

