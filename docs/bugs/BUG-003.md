# BUG-003 — Блок расписания не растягивался на 10:00–13:00

**Статус:** fixed (2026-06-18)

## Описание
В календаре указано время 10:00–13:00, но блок отображался только в строке 10:00.

## Причины
1. `end_time` часто не заполнялся (поле было спрятано в «Дополнительно»).
2. На экранах <1280px используется `garage-day-grid` без rowspan.

## Исправление
- `views/orders/form.ejs`: «Окончание» на основной форме.
- `controllers/orderController.js`: валидация `end_time > start_time`.
- `public/css/autoservice.css`: улучшение fill для spanning cells.

## Verify
```bash
npm test
# tests/calendar.test.js — multi-hour order spans three rows
# tests/orders.test.js — create order rejects invalid time range
```
