# BUG-002 — Нет поля VIN при привязке авто к записи

**Статус:** fixed (2026-06-18)

## Описание
При приёмке (`POST /orders/:id/car`) нельзя было ввести VIN; в заказ-наряде отображался «—».

## Ожидаемое поведение
- Поле VIN в форме привязки авто (опционально).
- VIN виден на карточке заказа и в печати.

## Исправление
- `views/orders/show.ejs`: `new_vin`, `new_year`, `new_body_type`; отображение VIN в шапке.
- Бэкенд уже поддерживал `new_vin` в `resolveOrCreateCar`.
